# Rare requests

## Before and after

If the user wants a before/after and the page renders now (a static file, or a dev server that is already running), take the before shots first with step 4's render command, naming the shot `before.png`: once you edit, there is no before state left to render, since git history is off limits.

## A named reference

"Like Linear" or "like Stripe": with its URL, read it with `${CLAUDE_PLUGIN_ROOT}/skills/design/references/read-a-reference.md`; its scale values (spacing unit, type ratio, radius steps, motion timing) replace the defaults in the principles, its rules never override them (one accent, shadows only on floating layers), and its hue, fonts, and assets stay behind. Without a URL, the principles alone are the path.

## A score or quality bar

Have the step 4 shots judged as in `${CLAUDE_PLUGIN_ROOT}/skills/redesign/references/critic.md`.
